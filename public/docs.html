API

Vizat 3 is a scene graph. You mount a Stage, add Layers, and put shapes on the layers. The stage owns hit testing, dragging, and wheel zoom.

Install

npm i vizat

Stage

import { Stage, Layer, Rect } from "vizat";

const stage = new Stage({
  container: "board",   // element or id
  width: 960,
  height: 600,
  background: "#12110f",
  wheelZoom: true,      // default
});
stage.resizeToContainer();
stage.add(new Layer());
  • zoomAt(factor, screen?) and resetView()
  • getIntersection(screen) — topmost shape
  • getPointerPosition() — world coordinates
  • toDataURL({ background }) — PNG of every layer
  • draggable(true) pans when the press misses a shape. Middle and right button always pan.
  • forcePanMode(true) pans even over shapes (the hand tool).

Shapes

Rect, Circle, Ellipse, Line, Arrow, Curve, Text, Star, Image, and Group.

const rect = new Rect({
  x: 40, y: 40, width: 160, height: 90,
  cornerRadius: 12,
  fill: "#243044",
  stroke: "#e8a25a",
  strokeWidth: 1.5,
  draggable: true,
  rotation: 0,
  opacity: 1,
});
rect.on("dragmove", () => {});
rect.on("click", () => {});

Getters and setters share a name: rect.x() reads, rect.x(20) writes. position(), scale(), and setAttrs() set several at once. tween({ x: 200 }, 0.4) eases a numeric attribute.

Circle and star coordinates are the center. Rectangle and text coordinates are the top left. Line and arrow points are a flat list: [x1, y1, x2, y2].

Transformer

import { Transformer } from "vizat";

const tr = new Transformer({ nodes: [rect] });
layer.add(tr);
rect.on("transform", () => tr.nodes()); // still the same nodes

Eight scale handles plus a rotate handle. Shift locks aspect and snaps rotation to 15°. Alt scales from the center. The box follows rotated nodes. Multi-select scales and rotates the set together.

Connectors

import { Connector } from "vizat";

layer.add(new Connector({
  from: client,
  to: worker,
  stroke: "#e8a25a",
  strokeWidth: 2,
}));

The arrow retargets both borders when either node fires dragmove or transform. Call refresh() after you set x or y yourself.

Events

pointerdown, pointermove, pointerup, click, dblclick, mouseenter, mouseleave, dragstart, dragmove, dragend, transformstart, transform, transformend, wheel. Events bubble. stopPropagation() cuts the bubble.

Serialize

import { createNode, linkConnectors } from "vizat";

const json = layer.getChildren().map((node) => node.toObject());
const restored = json.map((item) => createNode(item));
restored.forEach((node) => layer.add(node));
linkConnectors(layer.getChildren());
